Библиотека упражнений

Все модули: дозировка, темп и критерий перехода по каждой ступени, от R2 до P2. Свою ступень ты узнаёшь в планировщике трипа. Видео появятся рядом с упражнениями.

Модуль 1 · Общая физическая база

Rib Stack Hold

Держим положение грудной клетки (Rib Stack). Все четыре семейства Trim Lock тренируют один паттерн через разные входы. Берёшь 1–2 семейства на сессию и меняешь их каждую сессию.

  1. R2

    3×10-15 сек, отдых 30 сек

    Свободное дыхание

    Дальше: 15 сек без потери Rib Stack → R1

  2. R1

    3×20-30 сек, отдых 30-40 сек

    Вдох перед стартом, ровное дыхание

    Дальше: 30 сек стабильно 2 сессии → Base

  3. Base

    3×30-40 сек + поочерёдное вытяжение рук 4-6/рука, отдых 40-45 сек

    Выдох на вытяжении

    Дальше: Вытяжение без потери НПГ → P1

  4. P1

    3×30 сек с эспандером в руках, отдых 45 сек

    Выдох на вытяжении

    Дальше: НПГ держится под сопротивлением

  5. P2

    20 сек сразу после блока 6, без отдыха (тест)

    Дыхание сбито, это и есть тест

    Дальше: НПГ держится в утомлении → можно в Peak Set

Bird Dog

Заменяет «Лодочку»: тот же слот (антиротационная выносливость, задняя цепь), ниже технический порог дома, меньше нагрузка на поясницу, потому что вес на четырёх точках.

  1. R2

    2×6/сторону, удержание 3-5 сек, отдых 30 сек

    Только рука ИЛИ только нога

    Дальше: Таз не разворачивается → R1

  2. R1

    2×6-8/сторону, удержание 5 сек

    Рука + противоположная нога, медленно

    Дальше: Таз стабилен 2 сессии → Base

  3. Base

    3×8-10/сторону, удержание 8-10 сек

    То же, дольше в вытяжении

    Дальше: Без бокового наклона таза → P1

  4. P1

    3×8/сторону, удержание 10 сек

    Лёгкий эспандер или подушка под опорным коленом

    Дальше: Сопротивление без потери нейтрали → P2

  5. P2

    3×6-8/сторону, отдых 45 сек

    Пауза + лёгкое дополнительное тянущее усилие

    Дальше: Готовность к асимметрии модулей 3-4

Главная компенсация — наклон таза в сторону поднятой ноги. «Квадратный» таз важнее скорости прогрессии.

Rib Stack Extension

Trim Lock через разгибание плюс работа всех зон трапеции.

  1. R2

    3×8-10 циклов, отдых 30 сек

    Упор на оба локтя, прогиб грудного отдела, протракция/ретракция лопаток

  2. R1

    2×8-10/сторону, отдых 30-40 сек

    Упор на один локоть, свободный локоть уходит назад

  3. Base

    3×8-10, чередовать варианты по сессиям, отдых 40 сек

    Без опоры: локти назад поочерёдно (антиротация) или одновременно (сила разгибателей, руки не отрываются)

Подсказка для Base: поясница не отдыхает между повторами. Если в SRS у тебя флаг разгибания, это упражнение пропускаем. Ступень P1 появится по мере наработки.

Rib Stack Arch Entry

Готовит к будущим модулям. Постановка ноги на P1 — репетиция тейк-офа и мобильность ТБС, полезная и без трипа. Семейство начинается с R1.

  1. R1

    3×5-6, удержание 2-3 сек вверху, отдых 30-40 сек

    С четверенек в прогиб, голени приподняты, без отжимания

  2. Base

    3×6-8, отдых 40 сек

    Таз к полу → сгибание рук до Rib Stack → разгибание → подъём таза

  3. P1

    3×4-5/ногу, отдых 40-45 сек

    То же + на пике прогиба одна нога шагает вперёд к рукам

После уверенного Base ступень R2 в Rib Stack Arch (М3) даётся заметно легче.

Rib Stack Raises (Y/T/W)

  1. R2

    2×8 (только Y или T), отдых 30 сек

    Выдох на подъёме

    Дальше: Без компенсации шеей/поясницей → R1

  2. R1

    2×8 на положение, отдых 30-40 сек

    Пауза 1 сек вверху

    Дальше: Все три без потери лопатки → Base

  3. Base

    3×10 на положение, отдых 40 сек

    Без рывка

    Дальше: 2 сессии чисто → P1

  4. P1

    3×10, пауза 2 сек, отдых 40-45 сек

    Без задержки дыхания

    Дальше: Готовность к Rib Stack Row на этом уровне

Ранний отрыв локтей в тесте Wall slide (SRS): начинай с этого семейства, перед Row.

Rib Stack Row

  1. R2

    Изометрия, лёгкий эспандер, 2×10-15 сек

    Выдох на входе

    Дальше: Таз не вдавливается, колени не на полу → R1

  2. R1

    Полный диапазон, лёгкий, 2×8-10

    Выдох на тяге

    Дальше: Чистый диапазон → Base

  3. Base

    Средний, 3×10-12, отдых 40 сек

    Пауза 1 сек

    Дальше: 2 сессии стабильно → P1

  4. P1

    Тяжёлый, 3×8-10 + пауза 2 сек

    Выдох на тяге и паузе

    Дальше: Удержание под максимальной нагрузкой

Единый критерий: таз не вдавливается в пол, колени не опускаются. Тяга стоя (зал) — по желанию, самостоятельно, с критерием «стоп».

Pallof press

  1. R2

    2×6/сторону, с колен, минимальное сопротивление

    Выдох на вытягивании

    Дальше: Корпус без ротации → R1

  2. R1

    2×8/сторону, стоя

    Пауза 1 сек

    Дальше: Стабильно обе стороны → Base

  3. Base

    3×10/сторону + шаг в сторону

    Без задержки

    Дальше: 2 сессии без потери нейтрали → P1

  4. P1

    3×8/сторону + полуприсед на выставленную ногу

    Синхронно с ногой

    Дальше: Готовность к антиротации в движении

Слабая сторона в боковом упоре (SRS): больше подходов на той же ступени, без форсированного совместного перехода.

Асимметричный изометрический присед

2 подхода на ведущую ногу, 1 на заднюю.

  1. R2

    По времени: 3×10-15 сек, опора о стену. По повторениям: 3×6-8 (3-1-2), опора

    Дальше: 15 сек без вальгуса → R1

  2. R1

    По времени: 3×15-20 сек без опоры. По повторениям: 3×8-10 без опоры

    Дальше: 20 сек, колено не заваливается → Base

  3. Base

    По времени: 3×25-30 сек. По повторениям: 3×10-12, пауза внизу 2 сек

    Дальше: 2 сессии без компенсации → P1

  4. P1

    Эксцентрическая лесенка: шаг назад, медленно (3 сек) в асимметричный присед, вес на передней ноге. 3-4 повтора на ведущую, 2 на заднюю

    Дальше: Готовность к взрывной фазе тейк-офа

Если в SRS (приседания 45 секунд) колено уходит внутрь, ступень не ускоряем, независимо от готовности в остальных блоках.

Ротация грудной клетки относительно таза

  1. R2

    3×8/сторону, лёгкий эспандер, медленно

    Выдох на повороте

    Дальше: Без движения таза → R1

  2. R1

    3×10/сторону, лёгкий

    Выдох на повороте

    Дальше: 2 сессии стабильно → Base

  3. Base

    3×10-12/сторону, умеренный

    Быстро наружу, медленно обратно

    Дальше: Управляемая асимметрия → P1

  4. P1

    3×12-15/сторону, тяжёлый

    Быстро наружу, медленно обратно

    Дальше: Готовность к angle take-off

Медбол в стену (зал): когда P1 на эспандере выполняется технично.

Мобильность ТБС (PAILs/RAILs)

  1. R2

    Пассивно 90/90, 2×20-30 сек/сторону

    Свободно

    Дальше: Комфортно → R1

  2. R1

    PAILs: изометрия 5-10 сек в конце амплитуды

    Выдох в изометрии

    Дальше: Без дрожи → Base

  3. Base

    PAILs → RAILs 10/10 сек, 2-3 цикла

    Выдох на каждой фазе

    Дальше: Рост амплитуды за 2 сессии → P1

  4. P1

    То же, изометрия 15 сек

    Выдох на каждой фазе

    Дальше: Амплитуда переносится в динамику

Не форсируй растяжку. У тебя своя амплитуда, она меняется медленнее, чем сила. Для плеч та же логика.

Surf-Burpee

Стоя → присед, руки на пол → ноги назад в позицию гребли → взрывной выход ногой вперёд (чередуя) → стойка → прыжок. Техника тейк-офа не оценивается, следим только за Rib Stack в позиции гребли.

  1. R2

    3 раунда × 30 сек, отдых 20-40 сек

    Без прыжков

    Дальше: Все раунды без одышки → R1

  2. R1

    4 × 30 сек

    Взрывной выход + прыжок

    Дальше: Стабильный темп → Base

  3. Base

    4-5 × 40 сек

    Полная механика

    Дальше: Rib Stack держится до конца → P1

  4. P1

    5-6 × 40 сек, быстрее

    Полная механика

    Дальше: Готовность к Peak Set

Rib Stack проваливается уже на 3-м раунде Base: не добавляй раунды, а проверь восстановление (Eat-Sleep-Surf).

Модуль 2 · Гребля · Гребля

Rib Stack Paddle · Pull

Пропульсия. Руки работают поочерёдно (в отличие от Rib Stack Row, где тяга одновременная), это имитация реального гребка. Целевые мышцы: широчайшая и трицепс.

  1. R2

    Частичная амплитуда, без сопротивления, 3x20-30 сек, отдых 30 сек

    Свободное дыхание, приоритет — держать Rib Stack

    Дальше: Держит Rib Stack на всей амплитуде без сопротивления → R1

  2. R1

    Лёгкий эспандер, умеренная амплитуда, 3x20-30 сек, отдых 30-40 сек

    Дыхание синхронизировано с темпом гребка

    Дальше: Стабильный ритм дыхания, Rib Stack держится → Base

  3. Base

    Лёгкий-средний эспандер, полный паттерн, 3x30-40 сек, отдых 40 сек

    Темп ровный: техника, не скорость

    Дальше: 2 сессии без проваливания Rib Stack во второй половине подхода → P1

  4. P1

    Два сценария. Выход за линию прибоя / Out Set: тяжёлый эспандер, 4x15-20 сек взрывных серий, отдых 40-45 сек. Погоня за волной: средне-тяжёлый эспандер, 4x10-15 сек спринтов, отдых 30-35 сек

    Out Set: максимальная скорость и амплитуда, короткие мощные вспышки. Погоня за волной: резкий быстрый темп; за 2 сек до конца интервала 3 максимально мощных гребка (имитация финального рывка на поимку волны)

Вариант для ротации (только Base/P1), Pull Standing: стоя в наклоне, эспандер закреплён выше уровня головы (дверная петля/турник), прямая рука тянет по дуге сверху вниз к бедру. Та же дозировка. Вводится как дополнение, ротация с основным вариантом каждые 4-6 недель. На R2/R1 не используется. Фазу Recovery этого же гребка уже тренирует Rib Stack Raises из М1.

Rib Stack Paddle · Catch

Изолирует момент входа руки в воду и начало захвата, до полной тяги. Положение прону на лавке или другом возвышении (не на полу). Старт: Rib Stack, обе руки вытянуты вперёд. Одна рука за раз выполняет захват (около 20-30% полной дуги, кисть входит под небольшим углом вниз, на линии плеча), вторая остаётся вытянутой, удерживая Rib Stack.

  1. R2

    Без сопротивления, только позиционирование входа + микро-инициация тяги, 2x8/рука, отдых 30 сек

    Фокус на угол входа кисти, не на скорость

    Дальше: Чистый угол входа на обе руки → R1

  2. R1

    Лёгкий эспандер, та же микро-амплитуда, 2x10/рука, отдых 30 сек

    Выдох в момент захвата (начало тяги)

    Дальше: Стабильное включение широчайшей сразу на входе → Base

  3. Base

    Лёгкий-средний эспандер, амплитуда захвата около 30% от полной, 3x10/рука, отдых 35 сек

    Выдох в момент захвата (начало тяги)

    Дальше: 2 сессии без потери угла входа под утомлением → P1

  4. P1

    То же + ускоренный темп входа руки (тайминг под высокий stroke rate), 3x10/рука, отдых 35-40 сек

    Дыхание в такт ускоренному темпу

    Дальше: Готовность интегрировать точный вход в полный Pull на скорости

Зачем отдельно: неправильный угол входа руки снижает пропульсивную дистанцию гребка независимо от силы тяги. Вариант для ротации (только Base/P1), Catch Standing: та же стойка, что в Pull Standing, рука намеренно подсогнута в локте, амплитуда ограничена верхней частью дуги. На R2/R1 только вариант на лавке.

Rib Stack Paddle · Endurance

Тот же паттерн, что в Pull, но дозирован для субмаксимальной непрерывной ёмкости, а не для силы. Физиологически другая нагрузка, а не просто «то же самое дольше».

  1. R2

    Без сопротивления или лёгкий эспандер, непрерывно 45-60 сек, отдых 45 сек

    Ровное дыхание, приоритет — непрерывность движения

    Дальше: Проходит без остановки → R1

  2. R1

    Лёгкий эспандер, непрерывно 60-90 сек, отдых 45 сек

    Стабильный дыхательный ритм

    Дальше: Держит ритм без сбоя дыхания → Base

  3. Base

    Лёгкий эспандер, непрерывно 90-120 сек, отдых 45-60 сек

    Стабильный дыхательный ритм

    Дальше: 2 сессии без потери Rib Stack к концу подхода → P1

  4. P1

    Крейсерская гребля: лёгко-средний эспандер, 3x60-90 сек, отдых 45-60 сек

    Ровный экономичный темп, дыхательный ритм в приоритете

    Дальше: Готовность к фазе Building Swell

Крейсерский сценарий венчает именно эту лесенку: он ближе к выносливостному профилю, чем к спринтерским сценариям Pull.

Модуль 3 · Тейк-офф · Общая фаза (обе доски)

Rib Stack Push-up

Переход из позиции гребли в упор руками с завершающим прогибом без поворота. Постановка рук 45-50 см, симметричная нагрузка на обе руки, Rib Stack удерживается весь упор. Поворот в сторону волны здесь не добавляется.

  1. R2

    3x5 повт., частичный диапазон, медленно, отдых 30 сек

    Дальше: Rib Stack не проваливается на медленном темпе → R1

  2. R1

    3x5 повт., полный диапазон + прогиб без поворота, отдых 30-40 сек

    Дальше: Полный диапазон без потери Rib Stack → Base

  3. Base

    4x5 повт. + 3-5 имитационных гребков перед подходом, отдых 40 сек

    Дальше: 2 сессии стабильно на скорости, близкой к реальной → P1

  4. P1

    4x5 повт. + 3-5 имитационных гребков, полная скорость, отдых 40-45 сек

    Дальше: Rib Stack держится на полной скорости → готовность к следующим семействам

Все клиенты начинают с лонгборд-ветки: это обязательная база, а не выбор. Шортборд-ветка открывается после уверенного P1 в Longboard Rise.

Модуль 3 · Тейк-офф · Лонгборд: обязательная база

Rib Stack Arch

Выход из Rib Stack в положение прогиба с загрузкой рейла в сторону волны. Развивает грудные мышцы, руки, контроль Rib Stack при выходе в прогиб и мобильность под angle take-off на лонгборде.

  1. R2

    3x5-6 повт., отдых 40 сек, контролируемый (2-3 сек в прогиб)

    Выход из Rib Stack в прогиб, взгляд/разворот корпуса в сторону волны, загрузка рейла

  2. R1

    3x5-6 повт., отдых 40-45 сек, контролируемый

    То же + подтягивание ноги с полной постановкой стопы

  3. Base

    3x5-6 повт., отдых 45 сек, чуть медленнее (баланс без опоры стопой)

    То же, нога тянется к локтю, стопа остаётся навесу

  4. P1

    4x4-5 повт. + 3-5 имитационных гребков, отдых 45-50 сек, взрывной

    Более быстрый прогиб + взрывной выход в front step (Animal Flow)

  5. P2

    4x3-4 повт. + 3-5 имитационных гребков, отдых 50-60 сек, полная скорость

    Взрывной front step с загрузкой рейла и разворотом головы, максимально близко к angle take-off на лонгборде

Предупреждение, не запрет: если нет уверенного контроля ротации из М1 (ротация грудной клетки), начни с базового варианта этой ступени. Угол ротации при недостаточном контроле повышает риск компенсации через поясницу. Взгляд и разворот корпуса в сторону волны выполняются до подъёма, а не после.

Longboard Rise

Из положения Push-up: контролируемый скользящий подъём, ротационный контроль корпуса вместо компенсации руками. Сразу после подъёма давление уходит на переднюю ногу, а ведущая рука (одноимённая передней ноге) тянется вперёд.

  1. R2

    3x4 повт., отдых 45 сек

    Разбито на 3-4 счётные точки с паузами, медленно

    Дальше: Чистое прохождение всех точек → R1

  2. R1

    3x4 повт., отдых 45-60 сек

    Те же точки, короче паузы, более плавно

    Дальше: Сокращение пауз без потери контроля → Base

  3. Base

    4x4 повт. + 3-5 гребков перед каждым, отдых 60 сек

    Слитное движение, широкая стойка, взгляд/разворот к волне до подъёма, давление на переднюю ногу + вытяжение одноимённой руки

    Дальше: 2 сессии слитно, без компенсации руками → P1

  4. P1

    4x3 повт./сторону + 3-5 гребков, отдых 60-75 сек

    Angle take-off: тот же принцип ротации, что на шортборде

    Дальше: Готовность к фазе Peak Set

Предупреждение, не запрет: если нет уверенного контроля ротации из М1 (ротация грудной клетки), начни с базового варианта этой ступени. Угол ротации при недостаточном контроле повышает риск компенсации через поясницу. Если подъём идёт преимущественно за счёт упора руками (руки отрываются от доски позже, движение резче), кор ещё не готов к Base, задержись на R1. Уверенный P1 здесь открывает шортборд-ветку, но переходить сразу не обязательно: ветка самодостаточна для тех, чья цель только лонгборд.

Модуль 3 · Тейк-офф · Шортборд: продвинутая ступень

Rib Stack Tuck

Взрывной прогиб с подтягиванием коленей: от скольжения по полу до полноценного прыжкового элемента. В отличие от Rib Stack Arch (мобильность), здесь с первой ступени акцент на взрывное движение, под характер шортборд-тейк-офа.

  1. R2

    3x8-10 повт., отдых 40 сек, взрывной (простая механика)

    Взрывной прогиб со скольжением коленей по полу к линии пупка, голени навесу

  2. R1

    3x8-10 повт., отдых 40-45 сек, взрывной

    Колени отрываются от пола (не скользят), быстрое подтягивание к пупку, скольжение на носках

  3. Base

    4x10 повт., отдых 45 сек, взрывной

    Полный прыжковый элемент: толчок и приземление на две ноги, старт с носков

  4. P1

    4x8 повт. + 3-5 имитационных гребков, отдых 45-50 сек, максимально взрывной

    Голени отрываются сразу (без старта на носках), приземление на две ноги, руки ещё на полу

  5. P2

    4x5 повт./ногу + 3-5 имитационных гребков, отдых 50-60 сек, максимально взрывной

    Приземление на одну ногу поочерёдно: последний шаг перед полноценным pop-up на шортборде

Shortboard Pop-up

Из положения Push-up: взрывной подъём в стойку. На Base и P1 перед каждым повторением 3-5 имитационных гребков (Rib Stack Paddle Pull из М2), на R2/R1 без гребков: чистое обучение паттерну.

  1. R2

    3x5 повт., отдых 45 сек

    Промежуточное колено на пути к стойке, медленный контролируемый темп

    Дальше: Чистая техника с коленом на всех 5 повт. → R1

  2. R1

    3x5 повт., отдых 45-60 сек

    Без колена, взрывной выход, узкая стойка

    Дальше: Стабильно без колена, приземление в стойку → Base

  3. Base

    4x4 повт. + 3-5 гребков перед каждым, отдых 60 сек

    Полная скорость, взгляд/разворот к волне до подъёма, активное давление передней ногой сразу на приземлении

    Дальше: 2 сессии на полной скорости без потери формы → P1

  4. P1

    4x3 повт./сторону + 3-5 гребков, отдых 60-75 сек

    Angle take-off: подъём с ротацией под направление волны

    Дальше: Готовность к фазе Peak Set

Предупреждение, не запрет: если нет уверенного контроля ротации из М1 (ротация грудной клетки), начни с базового варианта этой ступени. Угол ротации при недостаточном контроле повышает риск компенсации через поясницу. Критерий приземления: не «устоял», а активное давление передней ногой в доску сразу на приземлении. Взгляд и разворот корпуса в сторону волны выполняются до подъёма, а не после.

Модуль 4 · Баланс и реактивность · Баланс и реактивность

PBT: реактивный баланс

Реактивный баланс тренируется непредсказуемыми толчками, а не удержанием позы. На одной ноге на каждой ступени R2-P1 три суб-шага по нестабильности опоры: твёрдая земля → подушка → одно скрученное полотенце.

  1. R2

    2x20-30 сек/нога на упражнение, твёрдая → подушка → одно полотенце, отдых 30 сек

    Одна нога: (а) вращение руками, (б) вращение рука+корпус+голова синхронно, (в) поочерёдное касание пола руками

  2. R1

    2-3x10-12 повт./нога, твёрдая → подушка → одно полотенце, отдых 30-40 сек

    Одна нога, теннисные мячи: (а) удар об пол и ловля поочерёдно, (б) подброс-ловля поочерёдно, (в) подброс одной/удар другой

  3. Base

    3x10-15 повт./нога, твёрдая → подушка → одно полотенце, отдых 35-40 сек

    Одна нога, мяч в стену/с партнёром: (а) удар в стену поочерёдно, (б) удар через пол в стену, (в) комбинация между руками

  4. P1

    3x8-10 повт./нога, твёрдая → подушка → одно полотенце, отдых 40-45 сек

    Extra: мячи на уровне груди ладонями вниз, отпускаем и ловим через быстрый подсед. Партнёрский вариант: партнёр стоит лицом и отпускает мяч(и), клиент реагирует и ловит

  5. P2

    2x5 толчков/нога (nudge/эспандер) или 2x8-10 перебросов/нога, отдых 45-60 сек между подходами

    Настоящий PBT: партнёр делает непредсказуемый nudge/towel-pull в разных направлениях. Соло-замена: эспандер, самостоятельный непредсказуемый рывок. Дополнительно: перебрасывание мячей с партнёром

Реактивность страдает первой при утомлении: блок P2 (непредсказуемые толчки) не растягивай до предела в конце сессии.

Полная стойка + Tail/Nose

Двуногая асимметричная стойка и смещение веса внутри неё. Ведущая нога даёт основной объём, неведущая меньший. Мячи с первой ступени: стоять или смещаться без задачи для рук неэффективно.

  1. R2

    3x20-30 сек (ведущая), 3x15-20 сек (неведущая), отдых 30 сек

    Статичное удержание асимметричной стойки + подбрасывание мячей (руки работают независимо от стойки), твёрдая земля

  2. R1

    3x8-10 циклов (ведущая), 3x6-8 (неведущая), отдых 30-40 сек

    Контролируемое смещение веса tail/nose + подбрасывание мячей во время смещения, твёрдая земля

  3. Base

    4x8-10 циклов (ведущая), 4x6-8 (неведущая), отдых 35-40 сек

    То же смещение + мячи, теперь на подушке под стойкой

  4. P1

    4x8 циклов, отдых 40-45 сек

    Tail/nose смещение + мячи на двух скрученных полотенцах. Альтернатива: то же на подушке + партнёр/стена с мячом (удар или переброс) вместо усложнения опоры

  5. P2

    3x20-30 сек удержания с работой мячей, отдых 45-50 сек

    Валик (свободное качение) + мячи: пик семейства, непрерывная нестабильность

Иерархия нестабильности опоры: твёрдая земля → подушка → полотенце (на одной ноге одно скрученное, два только для двуногой позиции) → валик.

Модуль 4 · Баланс и реактивность · Опционально

Slackline (по желанию)

Вариативное семейство, не основной путь: ограниченная доступность дома. Даёт постоянную мелкую непредсказуемую нестабильность. Вводится как альтернатива или дополнение на Base-P1 для тех, у кого есть слэклайн. Не заменяет семейства PBT и стойки.

  1. Base

    Дозировка пока не задана

    Базовое удержание одноногой стойки на линии; nose-to-tail смещения на линии (прямой аналог стойки Tail/Nose, но на постоянно нестабильной опоре); варьируемые стойки, приседания на линии с балансировкой

  2. P1

    Дозировка пока не задана

    То же, сложнее: nose-to-tail смещения, варьируемые стойки, приседания на линии

Балансборд (по желанию)

Зеркало семейства PBT: та же лестница, но на балансборде вместо земли, подушки и полотенец. Полностью опциональна, не влияет на прохождение модуля без неё.

  1. R2

    3x15-20 сек/нога на упражнение, отдых 30 сек

    Только вращения: руками / рука+корпус+голова синхронно, на балансборде. Касание пола исключено

  2. R1

    2-3x8-10 повт./нога, отдых 35-40 сек

    Только подброс-ловля мячей на балансборде

  3. Base

    2-3x8-10 повт./нога, отдых 35-40 сек

    Мячи в стену/с партнёром на балансборде

  4. P1

    2-3x6-8 повт./нога, отдых 40-45 сек

    Extra: подсед-ловля мячей на уровне груди на балансборде. Перед ловлей можно выполнять простое приседание без мяча как облегчённый вход

  5. P2

    2x4-5 попыток/нога, отдых 45-60 сек

    Балансборд + непредсказуемый партнёрский элемент (толчок/переброс)

Дозировка черновая: объёмы снижены относительно PBT, потому что сама опора добавляет сложность. Требует проверки на практике.

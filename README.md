# Eat-Sleep-Surf: инструменты

Небольшие веб-инструменты проекта Eat-Sleep-Surf.

- `index.html`: главная страница Eat-Sleep-Surf
- `srs/`: Surf-Ready Score, закрытая версия для беты: без переходов на главную и в планировщик, noindex. Не синхронизировать из артефакта, правки вносить вручную в этот файл
- `srs-team/`: Surf-Ready Score для команды, с переходом в планировщик; на неё ведёт планировщик
- `trips-planner/`: Планировщик трипа, Trips resident (календарь фаз по SRS и неделя тренировок), версия 0.3
- `library/`: Библиотека упражнений М1–М4

Новые инструменты кладутся в отдельные папки, у каждого своя постоянная ссылка.

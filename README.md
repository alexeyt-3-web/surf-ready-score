# Eat-Sleep-Surf: инструменты

Небольшие веб-инструменты проекта Eat-Sleep-Surf.

- `index.html`: Surf-Ready Score (самопроверка физической готовности, модуль 0)
- `trips-planner/`: Планировщик трипа, Trips resident (календарь фаз по SRS и неделя тренировок), версия 0.2.9
- `library/`: Библиотека упражнений М1–М4

Новые инструменты кладутся в отдельные папки, у каждого своя постоянная ссылка.
